# SyncWave

Навчальний пет-проєкт: браузерний сервіс формату Watch Party / SyncPlay для спільного синхронного
прослуховування музики й перегляду відео з друзями (наприклад, під час розмови в Discord).
Автор кидає посилання на кімнату, друзі відкривають його у звичайному браузері, вводять нікнейм —
і всі бачать/чують одне й те саме. Хост керує відтворенням, у кімнати спільна черга.
Репозиторій: https://github.com/y-teitelman/SyncWave (раніше акаунт називався KypicTiHKa — це той самий автор).

## Обмеження проєкту
- **Нульовий бюджет:** лише безкоштовні інструменти й сервіси, без купівлі домену чи платного хостингу
  (публічний доступ — через Cloudflare Quick Tunnel / ngrok або безкоштовний PaaS).
- **Друзям нічого не встановлювати:** клієнт працює лише в браузері (ПК і смартфон).
- Без реєстрації акаунтів: вхід у кімнату за посиланням + нікнейм.

## Стек
- C# / .NET 10 (LTS), `net10.0`, версія SDK закріплена в `global.json`
- xUnit для тестів
- CI: GitHub Actions (`.github/workflows/ci.yml`) — build + test на push і PR у `main`
- Редактор автора: VS Code + розширення C# Dev Kit (рекомендація в `.vscode/extensions.json`)
- ⚠️ У автора лімітований трафік: не пропонувати без потреби великі завантаження (важкі IDE, Docker-образи,
  зайві NuGet-пакети); якщо щось важке необхідне — попередити про розмір заздалегідь
- Заплановано: ASP.NET Core (завантаження файлів, стрімінг через HTTP Range Requests), SignalR, проста веб-сторінка з плеєром
- Потім, за бажанням: SQLite/PostgreSQL + EF Core, Redis, Docker

## Архітектура (Clean Architecture)
- `SyncWave.Core/` — доменна модель (`Entities/`, `Enums/`, далі `Interfaces/`), чистий C# без залежностей від вебу чи БД
- `SyncWave.Core.Tests/` — юніт-тести xUnit
- `SyncWave.Infrastructure/` — заплановано: файлова система, зовнішні сервіси
- `SyncWave.Web/` — заплановано: ASP.NET Core API, стрімінг, SignalR-хаб, веб-сторінка
- Стан кімнат на етапі MVP зберігається в пам'яті; медіафайли — на локальному диску

## Домовленості
- Назви тестів: `Метод_КолиУмова_ОчікуванийРезультат`, структура Arrange / Act / Assert, один виклик в Act.
- Документація типів — XML-коментарі з трьома слешами: `/// <summary>`; звичайні коментарі — українською.
- Приватні поля — `_camelCase` (`private readonly`); колекції назовні — `IReadOnlyList<T>` через `AsReadOnly()`.
- Обов'язкові властивості — `required`; незмінні після створення — `init`.
- Захисне програмування: Guard Clause і перевірка меж замість винятків (поточний стиль доменної моделі).
- Один тип — один файл; класи ядра — `public`.
- README існує у двох мовах: `README.md` (англійська, основний) і `README.uk.md` (українська).
  Будь-яка зміна змісту однієї версії має потрапити й в іншу; Claude нагадує про це, якщо автор змінив лише одну.
- Коміти англійською в стилі Conventional Commits: `feat:`, `fix:`, `test:`, `docs:`, `chore:`, `refactor:`.
